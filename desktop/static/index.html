Aperçu 3D & export

.glb : mesh + matériaux + photo aérienne (si cochée) dans un seul fichier autonome — aucune dépendance à Blender pour la récupération, c'est le format à préférer si ton logiciel le lit (Blender/Unreal/Unity/Maya récents). C'est aussi exactement ce qui s'affiche en direct sur le globe ci-contre (même fichier, deux usages). L'.OBJ contient déjà le mesh 3D (bâtiments extrudés, routes, mobilier) — importable tel quel dans Blender/Maya/Houdini, mais sans matériaux/texture (format historique). Alembic (.abc) est un format binaire qu'aucune librairie JS ne sait écrire de façon fiable dans un navigateur : le script Blender fait l'extrusion et l'export .abc natif en un clic, dans Blender. Avec « Photo aérienne » coché, l'.OBJ contient les UV mais pas l'image (l'exporteur OBJ ne sait pas écrire de .mtl/texture) — télécharge le .jpg séparément et réassigne-le à la main.
Sources : OpenStreetMap (Overpass API, licence ODbL) pour toutes les couches ; en France, les bâtiments peuvent aussi venir de la BD TOPO® IGN (Licence Ouverte Etalab) — hauteurs réelles issues de LIDAR (hauteur), plus fiables que les tags OSM souvent absents/estimés. Sélecteur « OSM / IGN » sur la ligne Bâtiments. Bâtiments : toits hip via un vrai squelette droit (straight-skeleton, WASM/CGAL) — correct sur n'importe quelle forme de contour, y compris concave ; repli automatique sur une approximation par champ de hauteur si la librairie échoue sur un contour dégénéré. Gable/ skillion/pyramidal via leurs méthodes dédiées. min_height/building:min_level gérés (socles, tours à étages). building:colour/roof:colour appliqués si hex valide. Cours intérieures (relations multipolygon) évidées dans le rendu 3D et dans l'export Blender (modifier Boolean par trou). Relief : case « Relief du terrain » (IGN RGE ALTI, France) — maillage adaptatif (Martini/RTIN, peu de triangles sur le plat, plus où le relief varie) au lieu d'un plan plat, dans le rendu 3D, l'OBJ, le .glb et le script Blender. Photo aérienne : case « Photo aérienne IGN » — texture le sol (pas les façades, une vue aérienne ne les voit jamais) ; embarquée directement dans le .glb, à réassigner à la main avec le .jpg pour l'OBJ/Blender. Zone conseillée : ≤ 1 km² par export pour rester raisonnable vis-à-vis des serveurs publics. Globe : CesiumJS (Apache 2.0), sans clé API ni compte — imagerie Esri World Street Map, terrain ellipsoïde (pas de relief satellite tiers, notre propre relief IGN reste la seule source d'élévation). Pas de 3D Tiles Cesium Ion / Google Photorealistic par choix explicite (éviterait la dépendance à une clé API payante/à quota).
