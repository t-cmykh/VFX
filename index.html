Aperçu 3D & export

L'.OBJ contient déjà le mesh 3D (bâtiments extrudés, routes, mobilier) — importable tel quel dans Blender/Maya/Houdini. Alembic (.abc) est un format binaire qu'aucune librairie JS ne sait écrire de façon fiable dans un navigateur : le script Blender fait l'extrusion et l'export .abc natif en un clic, dans Blender.
Source : OpenStreetMap (Overpass API), licence ODbL. Les hauteurs (height_est_m) sont estimées depuis le tag height ou building:levels×3m à défaut — à vérifier sur les bâtiments qui comptent pour un match caméra précis. Zone conseillée : ≤ 1 km² par export pour rester raisonnable vis-à-vis du serveur public Overpass.
