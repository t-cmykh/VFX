Aperçu 3D & export

L'.OBJ contient déjà le mesh 3D (bâtiments extrudés, routes, mobilier) — importable tel quel dans Blender/Maya/Houdini. Alembic (.abc) est un format binaire qu'aucune librairie JS ne sait écrire de façon fiable dans un navigateur : le script Blender fait l'extrusion et l'export .abc natif en un clic, dans Blender.
Sources : OpenStreetMap (Overpass API, licence ODbL) pour toutes les couches ; en France, les bâtiments peuvent aussi venir de la BD TOPO® IGN (Licence Ouverte Etalab) — hauteurs réelles issues de LIDAR (hauteur), plus fiables que les tags OSM souvent absents/estimés. Sélecteur « OSM / IGN » sur la ligne Bâtiments. Bâtiments : toits hip/gable/skillion/pyramidal réels (pas une approximation unique) — hip via un champ de hauteur (distance au bord le plus proche), correct sur n'importe quelle forme de contour, pas juste les rectangles. min_height/building:min_level gérés (socles, tours à étages). building:colour/roof:colour appliqués si hex valide. Cours intérieures (relations multipolygon) évidées dans l'aperçu 3D et dans l'export Blender (modifier Boolean par trou). Relief : case « Relief du terrain » (IGN RGE ALTI, France) — sol et objets suivent l'altitude réelle au lieu d'un plan plat, dans l'aperçu 3D, l'OBJ et le script Blender. Zone conseillée : ≤ 1 km² par export pour rester raisonnable vis-à-vis des serveurs publics.
